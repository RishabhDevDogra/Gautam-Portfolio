# Gautam Vashishth – Portfolio

A minimal, portfolio showcasing backend and platform engineering work. Built for GitHub Pages.

## Deploy to GitHub Pages

1. **Clone/create your repo:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/Portfolio.git
   git push -u origin main
   ```


## Update Links

Before deploying, customize these in `index.html`:
- `resume.pdf` → link to your actual resume
- GitHub URL in Contact section
- LinkedIn URL in Contact section
- Email address in Contact section
